### What I'm working on

#### [Sartor](https://github.com/sartorproj/sartor) — Intelligent Kubernetes Resource Optimization

A Kubernetes controller that observes real workload usage patterns and automatically right-sizes resource requests and limits via GitOps pull requests.

- Intent-based optimization profiles (Eco, Balanced, Critical)
- DSP-based time series forecasting with FFT and autocorrelation
- OOM protection, ArgoCD integration, Helm/Kustomize support
- Built in **Go** with a plugin-based recommendation engine

Also part of the Sartor ecosystem: **[goarima](https://github.com/sartorproj/goarima)** — an ARIMA forecasting library in Go, and **[sartor-ui](https://github.com/sartorproj/sartor-ui)** — the web dashboard.

#### [Codemem](https://github.com/mehrdadpfg/codemem) — Knowledge Graph for AI Coding Agents

A persistent memory and code intelligence layer that gives AI coding assistants (like Claude Code) deep, structured understanding of codebases.

- Symbol-level knowledge graph with semantic search (BM25 + vector)
- MCP server, REST API, and CLI interfaces
- Embedding providers: local (Candle), Ollama, OpenAI, Gemini
- Enrichment pipeline: static analysis to annotated graph
- Built in **Rust** (6-crate workspace) with a React/TypeScript UI
